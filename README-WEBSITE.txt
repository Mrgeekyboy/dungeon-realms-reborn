DUNGEON REALMS: REBORN — WEBSITE EDITION

Contains the full Milestone 10 game source: eight races, eight classes, racial abilities, talents, gear, leveling, town, five dungeons and bosses.

PUBLISH ON GITHUB PAGES:
1. Create a public GitHub repository named dungeon-realms-reborn.
2. Upload the extracted CONTENTS of this folder to the repository root, including index.html, style.css and the js directory.
3. In repository Settings > Pages, choose Deploy from a branch, main, /(root), then Save.
4. Wait for GitHub to show the published website URL in Settings > Pages.

Progress is saved locally to the browser and does not sync between devices or previous launcher origins.
This version is not yet confirmed through a full live browser playthrough.
